معماری دیپلوی فعلی

Browser → ArvanCloud (est.rysh.ir:443) ↓ Host:8000 → nginx_proxy ├─ /api /admin /static /media → django_app (gunicorn :8000) └─ / + /assets → React SPA (web build) django_app → postgres_db (:5432 internal) ۳ سرویس Docker (db / web / nginx) استاندارد و قابل‌قبول است. اپ menu/ در این دیپلوی سرو نمی‌شود.

نقاط قوت

  • TenantManager بدون tenant، queryset خالی برمی‌گرداند (جلوگیری از نشت داده بین رستوران‌ها).
  • Docker multi-stage: بیلد فرانت + بک‌اند + nginx جدا.
  • API client رستوران با baseURL نسبی مناسب پشت پروکسی.
  • لایه Super Admin جدا با permission اختصاصی.
  • RBAC پایه روی مدل User (get_permissions / has_section).
  • حفظ slug در مسیر بعد از لاگین در Login.jsx.

اولویت پیشنهادی اصلاح

  1. SEC-01 … SEC-04 — secrets در git، رمزهای compose، reset-password بدون OTP، ثبت‌نام با role دلخواه
  2. BUG-01 … BUG-03 + FE-01 + ARCH-01 — tenant خالی، دوگانگی middleware، JWT blacklist، super_client روی localhost
  3. SEC-05/06/09، BUG-04، FE-02 — CORS، validators، پرداخت، منوی عمومی، slug در redirect
